# 开工材料模板

填写已经确定的内容即可；没有旧页面、品牌素材或公开参考网址时可写“无”。路径只发给执行任务的 Agent，不必提交到公开仓库。

```text
使用 landing-from-reference 技能制作产品 Landing。

产品名：
一句话定位与目标用户：
源码目录或压缩包：
产品说明（无代码时提供）：
已完成的核心能力：
尚未完成、不可宣传的能力：

参考录屏路径：
参考网址（可选）：
想借鉴的部分：结构 / 动效 / 卡片 / 视觉气质 / 其他
旧页面：不参考其设计 / 保留指定部分 / 无
品牌素材与截图：
二维码（如需）：图片路径、平台、有效期

页面性质：产品内首页 / 独立展示
主要按钮：名称、目的地或禁用状态
返回方式：进入产品后如何回到 Landing
报名：不需要 / 保存字段、接收地址或数据表、提交后的行为
必须有的模块：
语言与品牌偏好：

本次范围：先预览 / 项目代码 / 单文件 HTML / 部署 / GitHub
允许修改的目录或分支：
部署目标（如已授权）：域名、子路径、已有服务与登录方式
不要改动的内容：
```

不要把密码或密钥写进这个模板文件。服务器可以使用现有 SSH 配置或由用户在适合的认证界面完成登录。
